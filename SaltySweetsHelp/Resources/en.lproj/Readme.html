SaltySweets Documentation

Chances are, the answer you're looking for is somewhere in these documents! Read the documentation pages first prior to reaching out for help.

SaltySweets is the controlling application for two tweaks, libIconRefCapture and libDockReflections.

You can use the tweaks independedently of each other.
You can disable both tweaks while leaving them installed.
You can use them with either Ammonia or PluginPlayground (PP), although the tweaks are designed for PP for versions >= Tahoe.
